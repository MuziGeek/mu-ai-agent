### 站点落盘的换行符事实（更正 9-16 的记录）

之前记的是「技能落盘写 LF，CRLF 由 git 提交时转换」，**不准确**：
本次落盘的 #10 直接就是 CRLF（464 个 CR）。而 #07/#08/#09 在工作区是 LF。

→ 结论：换行符取决于**正文文件自身**的换行符（Write 工具在 Windows 上产出 CRLF）。
站点 `core.autocrlf=true`，两种形式提交后都由 git 归一化，功能上无差异。
不必再纠结落盘用哪种，按站点 `doctor` 报的 CRLF 约定即可。
