# ✅腾讯面试流程

			 					

腾讯的流程一般是1轮笔试+3轮技术面 +1轮HR 面 

 				

:::color1
笔试:(不一定有) 

一面: 计算机基础 + 算法 

二面: 项目 + 技术 + 算法 

三面: 项目深入  
HR 面 

:::

 				 			

总结:

  
 一般 2-5 天一轮，线下的话当天或隔天 ;

  
 每轮面试大概一个小时左右，每轮有 2-3 个算法 ;
