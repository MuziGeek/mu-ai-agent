# ============================================================================
# 敏感词词库文件
# ============================================================================
#
# 【文件格式说明】
#   - 每行一个敏感词
#   - 以 # 开头的行为注释，会被 SensitiveWordFilter 忽略
#   - 空行会被忽略
#   - 词的前后空格会被自动去除（trim）
#
# 【如何维护词库】
#   1. 直接在本文件中添加/删除词即可，无需修改代码
#   2. 修改后需要重启应用才能生效（词库在 @PostConstruct 时一次性加载）
#   3. 建议按类别分组，便于管理和审查
#
# 【进阶优化思路】
#   - 如果需要热更新（不重启即可更新词库），可以：
#     a. 将词库存入数据库，提供管理接口
#     b. 监听文件变更事件，动态重新加载
#     c. 接入第三方敏感词服务 API
#   - 如果需要支持多种敏感等级（如"高危"直接拒绝、"低危"仅替换），
#     可以扩展文件格式为 "词,等级" 的 CSV 格式
#
# ============================================================================
